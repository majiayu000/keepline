# 实现与验收

## 实现

- 设置窗口改为左侧分类导航，右侧为带说明的设置行；输入关键字跨分类过滤。
- 通用：默认 Agent、回来时显示总览的分钟数、旧会话收起天数。
- 外观与终端：跟随系统/亮色/暗色，等宽字体、字号、行距，以及实际终端画笔绘制的预览。
- 快捷键：保留已有录制、冲突处理和恢复默认；搜索中也能录制。
- 通知：使用现有 notifications 偏好，说明 macOS 通知权限的影响。
- 工作区偏好经既有 Edit::Settings 保存，成功读回后刷新控件；保存中阻止重复提交，错误显示在设置底栏。
- 字体设置保存在 XDG_CONFIG_HOME/keepline/terminal-text.json（未设置 XDG 时使用用户配置目录）；保存失败不切换内存值。
- 字体、字号、行距参与终端单元格度量缓存，改变后终端重新计算网格。

## 验收协议

在独立的临时 runtime 与 XDG_CONFIG_HOME 下运行原生 visual-test，不接管用户工作会话。
通过 GPUI 原生鼠标/键盘事件点击分类、修改设置和搜索，保存渲染 PNG。
检查 Edit::Settings 的真实守护进程读回和字体配置文件，并在第二次应用启动时检查保留值。
另外运行相关 Rust 设置、终端度量和快捷键测试，检查独立终端渲染示例能编译。

已验：实际渲染的亮暗设置、搜索结果与空结果、失败保存提示、重启后的终端文字；没验：系统通知弹出及真人输入法；相邻情况：原有快捷键冲突、录制、重启保留与恢复默认另做原生回归。
