偷看、置顶与侧栏答审批

三件事都发生在左栏的同一行上：看一眼别的 Agent 在干嘛（Peek）、把盯着的几个钉在上面（置顶）、等你批准时不切过去就答（拓展 1b）。下面三个方向差别在「答审批时你看得到多少上下文」。

  • 点左栏任意一行（或终端里提到的终端号）浮出它的实时画面，压在当前标签上面；Esc 或 ✕ 关掉，「↗ 打开」才真正切过去。
  • 等你批准时，浮层标题栏直接给「允许一次 / 拒绝」——答之前看得到 Agent 的上下文。选项超过三个或识别不确定时只给「打开」。
  • 浮层里也能直接打字，输入进被看的那个终端（Herdr App 的做法，粘贴同理）。
  • 置顶：行尾悬停出现圆点，钉住后归到最上面的「置顶」组，会话结束自动取消。

三个方向共同的规则

项规则
能答哪些只答识别得出的审批框（规则 approval，见「为什么是这个状态」里的规则名）；按键只发给那个画面的终端，不改 Agent 自己的权限或信任设置。
防误发点按钮的那一刻重读一次画面，审批框已经不在就不发，提示「已经答过了」。
性能偷看复用该终端现有的画面数据，不另开订阅；浮层关掉即释放，不加定时器。
置顶只存终端 id，会话结束自动取消；不改分组口径。
