# 桌面工作台连远程机器：开工说明

状态：未开工（2026-11-02 写）。11-01 用户要求「多本机、多远程、移动端」都能用，不用 Tailscale。协议第一步（`keeplined remote --stdio`）当时就是为此做的，并且已经测过真实的 ssh 一跳：`ssh localhost` 下 20 次按键 p95 0.2 ms，`hello` 加上 ssh 建连 177 ms。

## 要支撑的决定

Keepline App 能不能把另一台机器（另一台 Mac 或 Linux 服务器）上的终端和会话，像本机的一样放进侧栏：看状态、看画面、打字、答审批，之后再加上接管、改尺寸和新开终端。同时要做到两点：
- 本机后台的信任模型不变，只认本机当前用户；
- 和手机共用同一套 [远程协议](remote-protocol.md)，不再另开一套内部协议。

## 两条路（建议 A）

| | A. App 走远程协议（建议） | B. 把远端后台的 socket 转发过来 |
|---|---|---|
| 怎么连 | App 起 `ssh 主机 keeplined remote --stdio`，每台机器一条 | `ssh -L` 把远端的 Unix socket 映射到本地，App 当成第二个本机后台 |
| 现在就能用的 | list、events、watch、send、keys、answer | 全部，包括接管、改尺寸、新开终端、对话内容 |
| 缺的 | 接管写入、改尺寸、新开 / 关闭终端、对话内容层（卡片）。要升协议 v2 | 两端内部协议必须同一个版本；App 里很多地方默认后台在本机（打开访达、本地路径、cwd），要逐个改 |
| 和手机的关系 | 同一套协议，手机以后也能用新加的操作 | 手机用不上 |
| 权限 | 走 SSH 时由 SSH 认证；走中继时按设备权限 | 等于把整个后台交出去 |

选 A 的理由：协议是对外的、稳定的，手机和桌面一起受益；B 能更快看到全部功能，但会把内部协议变成对外接口，以后很难改。

## 分步（A）

1. **只看**
   - 设置里加「远程机器」：填 SSH 主机名（读 `~/.ssh/config`）。App 为每台机器起一个 `remote --stdio` 子进程。
   - 侧栏按机器分组，本机在最上面。远程终端用 `list` 加 `events` 显示状态，点开用 `watch` 看画面，标成只读。
   - 终端按「机器 ID + 终端 ID」区分，`machine-id` 已经有了。
   - 验收：连一台真的另一台机器，画面和状态跟本机显示一致；断网后侧栏标「断开」，恢复后 5 秒内自己连回。
2. **打字和审批**：`send`、`keys`、`answer`，画面里按键直接走 `keys`。
   - 验收：按键回显 p95 ≤ 200 ms（局域网和跨公网各测一次）。
3. **协议 v2：接管和改尺寸**
   - 加 `take`（成为写入的一方）和 `resize`。
   - 和 [多客户端第三步](multi-client-events.md)（按最后操作的客户端调尺寸）一起做，手机也会受益。
   - `hello` 的 `ops` 里声明新操作，老客户端不受影响。
4. **新开、关闭终端，以及对话内容**：卡片、分组、鸟瞰要能看到远程会话。这一步改动最大，前三步用下来确实需要再做。
5. **不用 SSH，改走中继**：用 `full` 权限的设备身份，复用 `keepline-remote` 库，App 里的代码本来就是 Rust。

## 验收门槛

| 指标 | 门槛 |
|---|---|
| 按键到回显（SSH，跨两台真实机器） | p95 ≤ 200 ms |
| 一台远程机器断开 | 本机和别的机器不受影响，侧栏标断开 |
| 远程 `keeplined` 版本太老 | 明确提示「对方版本过低，请升级」，不报一串错误 |
| 没配远程机器时 | App 零开销，不起任何子进程 |

## 前提和要你定的

- **先连哪类机器**：另一台 Mac，还是 Linux 服务器？
  - `keeplined` 只有 `pty.rs` 一处区分了 macOS，其余看起来能跨平台，但**没在 Linux 上编译、运行过**。
  - 如果先连 Linux，第 0 步就是在 Linux 上编译并跑通后台测试。
- **远端怎么装 `keeplined`**：先手动拷二进制，还是做一键安装？建议先手动。
- **和手机 App 谁先做**：两者共用协议，互不阻塞。协议 v2（第 3 步）对两边都有用。

## 放弃条件

- 第 3 步做下来，App 要为本机和远程维护两套终端代码，而且差异越来越大 → 改走 B，或者让本机也走远程协议，只留一套代码。
- 用户两周内没有真正连上一台远程机器用 → 停在第 2 步。

## 没验

- 没跨两台真实机器测过，只测过 `ssh localhost`。
- 没在 Linux 上编译、运行过 `keeplined`。
