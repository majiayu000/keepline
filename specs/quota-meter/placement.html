额度摆放方向

2026-11-02 · 用于决定额度在工作台里放哪 · 先看了别家：调研记录 · 条的样式已定为竖条纹：额度条方向稿

三家现在的真实读数：Codex 5h 0%、周 100%；Claude 5h 3%、周 22%；Grok 周 52%。问题不是「怎么画条」，而是放在哪：额度常驻在侧栏底部要占 90px 左右，侧栏收起就看不到，而且看不出「这个会话还能跑多久」。

要支撑的决定额度的主位置选 A / B / C 哪一个
判断标准不点就能看到最紧的那个窗口；接近上限时一眼注意到；不挤占会话列表
放弃条件三个都比现在差，就保留侧栏底部，只补倒计时和旧读数标记

A · 留在侧栏底部，补上倒计时和旧读数标记

位置不动。每家一行、两个窗口并排，百分比后面直接写还有多久重置；读数旧了名字后面打 *，条变灰。悬停或点击打开和 B 一样的明细弹层。

参考：同类终端工具-status-ui-bar 的 * 旧读数标记；同类终端工具-quotabar 的「35% 24m」倒计时写法。

B · 顶栏右侧一行，点开看全部

每家只显示最紧的那个窗口：名字、一截短条、百分比。点开弹层看全部窗口、重置时间、读数来源和读数时间。侧栏底部空出来全部给会话。

C · 跟着会话走

额度不单独成区，挂在用到它的地方：会话行右侧用一截小条显示这个会话所用 Agent 最紧的窗口；超过 95% 时，那个窗格的标题栏亮一条提醒。侧栏底部只留一行很淡的汇总。

我的建议：B 做主位置，借 C 的窗格提醒

  • 主位置用 B：顶栏右边本来就空，侧栏收起也看得到，侧栏底部还给会话。每家只显示最紧的窗口，正好符合「扫一眼知道谁快到头」。
  • 借 C 的一处：只有某家超过 95% 时，用到它的窗格标题栏亮一条提醒（带重置倒计时）。平时会话行不显示额度，避免重复。
  • 弹层：放全部窗口、具体重置时间、来源和读数时间，以及哪几家本机没有记录。以后如果做「主动刷新」，开关也放在这里。
  • 不选 A 的原因：常驻占地方，而且侧栏收起就没了。如果你更看重「不点就能看到全部窗口」，A 仍然是最稳的选择。
