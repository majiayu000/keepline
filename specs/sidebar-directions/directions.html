侧栏方向稿

同一份数据，三种侧栏，并排比较。右边灰色条纹代表终端。每个都能点：A 悬停会话看「偷看」、点空间名切换；B 点任务展开收起；C 直接点「允许 / 拒绝」或打字回答，左上角能收成窄条。

A会话优先

空间收成顶上一行，整条侧栏给会话。每行多一行小字，用来区分会话、说清它停在哪。

Codex 额度 62%
  • 上半屏让给会话：空间平时只占一行，点开才是列表；数量为 0 的空间不常驻。
  • 每行能区分：第二行是 Agent 标记、短编号，再加它最后说的半句话或做完的结果（改了几个文件、测试过没）。
  • 行尾只放时间：在跑的显示本轮计时，其余显示多久前；状态只靠左边的圆点和第二行文字。
  • 悬停半秒偷看：不切过去也能看到终端最后几行。
  • 空间行不再显示橙色计数，「需要你」只留在顶栏和行本身。

B任务线

待办和会话合成一条线：一件事一行，派给 Agent 后会话挂在它下面，按时间分「刚刚 / 今天 / 更早」。

工作空间▾3 件事在做
Codex 额度 62%
  • 一件事一行：左边的进度图标从虚线圈（没开始）到半圈（做着）到勾（做完），和看板列头一致。
  • 会话挂在事情下面：三个「标签命名」会话不再是三行同名的，而是同一件事的三次尝试。
  • 没开始的事就在线上：行尾一个「开始」，不用再去折叠的待办区找。
  • 没归到任何待办的会话自己成一行，照样按时间排。
  • 代价：结构改动最大，要先确认「一个会话属于哪件事」能认准。

C在侧栏里回答

等你的会话变成卡片，问什么就地回：是非题点按钮，开放题打一句话。其余会话压成紧凑的一行行。

工作空间▾3 个等你
Codex 额度 62%
  • 大部分等待只差一下：「要不要推送」「允许执行这条命令吗」点一下就回，不用切到终端。
  • 开放题打一句话：回车发给那个终端，等于你在终端里打字。
  • 窄条模式：点左上角「⇤」收成 48px 的竖条，终端全屏时也能看到谁在等你（橙点在闪）。
  • 代价：要可靠地认出这是不是是非题；认不准的只给「打开终端」，不猜。
