B · 合并成一行 推荐

去掉面包屑行，标签直接放进顶部标题行：左边是空间名（点开切空间），右边是鸟瞰和新建。当前标签是白色浮起的小块。顶部少 34px，标题只在标签和窗格头出现。和 T3 Code / Arc 的做法一致，也接着上一轮「左栏到顶」的方向。
