# 工作台视觉规范（GPUI 实现用）

来源：同目录的设计稿（`*.dc.html`，即画布 https://claude.ai/artifact/D7QTQJmv6VZdPeqcKwHxoU 的源文件，可直接用浏览器打开看效果）。本文件把设计稿里的数值整理成 token 和组件规则；实现时**只用这里的 token**，不在组件里写散落的颜色和尺寸。

| 设计稿 | 对应界面 |
|---|---|
| `Main.dc.html` | 分屏工作视图（左栏、标签行、待办信息条、画面与状态栏、空位、「你在这里」弹窗、底栏） |
| `Overview.dc.html` | 鸟瞰视图（待办行、分组卡片、折叠计数） |
| `TodoNew.dc.html` / `TodoDetail.dc.html` / `TodoStart.dc.html` | 新建待办、待办详情、从待办开始的预填画面 |
| `Cleanup.dc.html` / `Menubar.dc.html` | 逐个清理、菜单栏弹窗 |

## 1. Token

以一个 `Theme` 结构集中定义，组件只引用字段名。`theme.rs` 里的测试会拒绝工作台组件（`workbench/`、`pane.rs`、`field.rs`、`desktop.rs`）中出现的六位十六进制颜色和数字 `px(...)`。

2026-10-23 起，界面颜色不再逐个手填：终端默认背景 `TERMINAL_BG`（`#101217`）和前景 `TERMINAL_FG`（`#d7dae0`）是两个基色，其余表面和文字色都由 `mix(from, to, 千分比)` 从这两个基色（加强调色 `#4b4fd6`、白和黑）混出来，所以改终端基色时，整个窗口会跟着一起变。下表的值是混出来的近似结果，以 `theme.rs` 为准。分组颜色只保留「点」这一个基色：浅色字为点色混 62% 白，深色底为终端背景混 25% 点色。

## 2. 组件

1. **左栏行**：高 30，左右内边距 8；左侧 7–8px 圆点（分组色），文字截断不换行；右侧计数或角标。选中时底 `bg.raised`、字 `text.primary`。分区标题 11.5、`text.secondary`，带 4px 下边距。
2. **标签**：等宽字体 12.5，左右内边距 12；选中底 `bg.raised`、字白色，未选中字 `text.secondary`；待办标签前有 11px 勾选框图标（`accent.text`）；右侧 7px 分组色点；行末「＋」按钮。
3. **待办信息条**：底 `bg.todo_bar`；左侧「待办」小标签（`accent.chip_bg` 底、`accent.text` 字、11 号、圆角 4）、待办名（13 粗）、验收进度（12、`text.secondary`）；右侧「待办详情」文字链接与「标记待办完成」描边按钮（高 26）。
4. **画面**：圆角 8、1px 边框；聚焦时边框 `accent`、状态栏 `bg.pane_header_focused`。状态栏从左到右：分组小标签 → 一句「你在这里」摘要（截断）→ Agent · 时间（`text.secondary`）→「你在这里」描边按钮 → 分屏图标按钮（24×22）→「⋯」→「×」。
5. **空位**：1px 虚线边框 `#2f3448`、底 `bg.slot`，内容垂直居中：一行说明、主按钮（带 Agent 下拉的分体按钮）、次按钮「开一个空终端」、一行 11.5 提示。
6. **按钮**：主按钮底 `accent`、白字、600、高 30–34、圆角 6–8；描边按钮透明底、`border.control`、字 `text.body`；图标按钮必须有无障碍名称。每个功能都有可见按钮，首版不做快捷键。
7. **「你在这里」弹窗**：锚定在所属画面内右上角（距边 10），宽 `min(340, 画面宽 − 20)`，超出时内部滚动；内容为四行定义列表（你要它 / 做成了 / 停在 / 下一步·推断）和底部三个结局按钮。不得溢出画面或窗口。
8. **鸟瞰卡片**：圆角 10、底 `#12141a`、边框 `#22252f`；标题 13.5 粗、元信息 11.5、状态一句 12.5 用分组浅色字；「新」标记为浅底深字小标签；网格自适应列数（最小列宽 230）。

## 3. 实现约束

- 颜色、字号、间距全部来自 `Theme`；代码里出现裸十六进制颜色或裸像素数字视为未按规范实现（终端单元格颜色除外）。
- 先对齐 `Main.dc.html` 的整体结构与比例，再逐个组件对照；完成后与设计稿在同一窗口尺寸（1440×900）下并排截图比对。
- 资源约束不变：只绘制可见画面，空闲不重绘（沿用 GPUI 空闲补丁）。
