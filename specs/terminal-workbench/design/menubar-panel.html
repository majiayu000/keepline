改了什么（对照 2026-10-22 实拍 menubar-native.png）

  • 标题从「2 个在等你 · 0 个出错」改为一个数「3 项需要你」，四格计数（等你回答 / 出错 / 待核对 / 在跑）取代灰色的「另有 … 」一行；0 用弱色，不显示状态色。
  • 行不再给第一项常驻橙底：行之间用细线，悬停或键盘焦点才铺浅底。状态色只在点和第二行原话上。年龄列右对齐、等宽数字。
  • 页脚两行说明压成一行：「很久没动 38」+ 右侧「外部会话在鸟瞰里看」。超过 5 项时在列表下加「还有 N 项」文字链接（现有 footer 文案已有这个数）。
  • 每个视图只有一个实心按钮「打开工作台」；离线时也保持它，重连是自动的，所以只给「复制错误」「查看诊断」两个文字按钮。
  • 深色：macOS 深色模式下现在仍是白底面板。深色版取 README 跨界面主题的深色一行，强调色换成近白。
