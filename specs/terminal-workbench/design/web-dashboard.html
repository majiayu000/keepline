改了什么

  • 状态色只用在点和细条上：今天 --success 是靛蓝、--danger 是琥珀，出错和需要输入长得一样；改成需要你（橙）、出错（红）、待核对（紫蓝）、运行（绿）、停下（黄褐）、空闲/结束（灰）六种。
  • 卡片去掉左侧彩色竖边和常驻高亮底，靠细边框分隔；需要你的卡片只在「当前动作」那一行铺浅橙底。
  • 每个页面一个实心按钮：会话页是「同步」，总览页是「逐个处理」；其余按钮为浅底或描边。
  • 侧栏今天是深色 #111318（浅色模式下也是），改成和主区同一套变量的次底色，深浅切换时一起变。品牌方块的渐变去掉。
  • 图只放在数据撑得住的地方：费用有每天的值（14 根细柱 + 日均虚线 + 直接标今天）；回合数有时间戳。会话计数之间差距大（完成 112），分布条只画未结束的。

建议的 CSS 变量（替换 index.css 里的 :root，深色挂在 :root[data-theme="dark"]）

迁移面：src/web/client/src 下 15 个文件里写死了 377 处十六进制颜色，最多的是 #6B7280（70 处 → --text-2）、#FFF（52 → --surface / --on-accent）、#4F5BD5（38 → --accent 或 --st-run，按用途分）、#15171C（30 → --text）、#B45309（15 → --st-need）。presentation.ts 里的 tagBg / tagFg / itemColors 和 LedgerOverview 里活动点的内联色要改成返回变量名。旧变量名（--primary、--bg-base、--text-dim 等）可以先指向新变量，逐个模块替换后再删。
