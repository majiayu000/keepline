# 界面收紧：去重、配色推导、「你在这里」精简（2026-10-23，无模型）

起因：与 ELYTerminal（GPUI + Ely 组件的通用终端）对比界面设计后，采用以下四项。

1. **去掉重复的界面部件**：删掉左栏底部的「鸟瞰全部」按钮和「N 个会话 · 终端宿主已连接」；入口只留在顶栏，状态只留在底栏。空间行的会话总数改为「共 N」，和等你、出错角标区分开。
2. **配色从终端基色推导**：`theme.rs` 用 `mix()` 从终端默认背景和前景（加强调色）混出全部界面色，分组的浅色字和深色底由分组的点色推导。「你在这里」卡片和逐个清理页从白底改为深色。菜单栏弹窗保持浅色。
3. **「你在这里」只常驻两个操作**：「继续」+「已验收」（已有结局时换成「撤销结局」），其余四个操作收进「更多 ⋯」。顺带修好体验清单中「没有结局也显示撤销结局」的问题。
4. **拆分与 token 约束**：`workbench.rs`（4512 行）拆成 `workbench/` 下 13 个模块，最大的是 `mod.rs`（约 730 行）。`render` 中的左栏和表单面板拆成独立方法。新增测试，拒绝组件中出现颜色和像素字面量。

## 证据

- `before/`、`after/`：同一份隔离数据下 GPUI `render_to_image` 的输出，尺寸 1440×900 @2x。数据来自 [visual-20261021 夹具](../visual-20261021/fixture.py)，换成 debug 后台，页面为 Main、ScreenWait、Overview、Cleanup。`after/` 另有 `heremore`（展开「更多」）和 `todonew` 两页。
- `cargo test --workspace`：app 31、core 21、daemon 32、integration 27 项全部通过，另有 1 项按设计 ignored。`cargo clippy -p keepline-app --all-targets` 没有新增告警；`screen::capture` 未使用是已有问题。

## 未验证

- 没有用真实 Agent 在用户自己的工作台里点过「更多」和结局按钮，只看了渲染结果。
- 配色推导目前是编译期常量。终端运行时通过 OSC 11 改背景色，界面不会跟着变。

## 第二轮：去掉底栏，改中性灰（同日）

用户看过第一轮后反馈：「整体没啥变化，不如 ELYTerminal 好看」。和本机源码构建的 ELYTerminal 0.1.8 并排截图对比后发现，差距在终端外面那一圈界面：ELY 整个窗口是一块中性灰，只用细线分区，控件没有边框；Keepline 有五条深浅不同的横栏，按钮都有边框，还用了靛蓝强调色。用户定的范围：去掉底栏，保留顶栏，其余改配色。

- **底栏去掉**：「下一个等你的 · N」移到顶栏；后台更新中时，顶栏显示「正在更新…」。
- **中性灰配色**：终端基色改为 `#1c1c1e` / `#e4e2df`。左栏、顶栏、画面和状态栏用同一块底色；界面不再用彩色，彩色只留给分组状态。主按钮改为近白底配深色字，聚焦边框改为灰色。菜单栏弹窗保留靛蓝。
- **按钮去边框**：平时无边框、无底色，悬停时出现浅底。
- **顶栏即标题栏**：标题栏改为透明，红绿灯放进顶栏左侧；顶栏空白处可以拖动窗口，双击缩放。鸟瞰、搜索和逐个清理这些整页视图，顶部也留出同高的一行给红绿灯。

证据在 `neutral/`。其中 `main-live-window.png` 是真实窗口截图（`screencapture -l`），带系统红绿灯；其余是 `render_to_image` 渲染图，不含红绿灯。

仍未验证：拖动窗口和双击缩放没有亲手试过；窗口宽度小于约 1000 时，顶栏是否放得下也没有检查。
