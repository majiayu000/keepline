# 快捷键与设置面板

## 要支撑的决定

终端工作台是否用一套集中、可改的快捷键，替代散落在 `workbench/render.rs` 与 `terminal/pane.rs` 的硬编码匹配，并给出设置入口。

- 采用条件：默认键位与 Ghostty / Warp / iTerm2 的肌肉记忆一致；改绑后新键生效、旧键失效、重启保留；不含 ⌘ 的组合键始终原样交给终端程序。
- 放弃条件：如果集中判定导致 ⌘C / ⌘V / 输入法组合或终端程序收到错误按键（回归），回到硬编码匹配，只保留设置面板的展示。

## 动作与默认键位

默认值来自本机 `ghostty +list-keybinds --default`（Ghostty 已安装），Warp / iTerm2 在这些项上相同。

| 动作 | 默认 | 处理方 |
|---|---|---|
| 新建标签 | ⌘T | 工作台 |
| 关闭画面（最后一个画面时关闭标签） | ⌘W | 工作台 |
| 向右分屏 / 向下分屏 | ⌘D / ⌘⇧D | 工作台 |
| 上一个 / 下一个标签（循环） | ⌘⇧[ / ⌘⇧] | 工作台 |
| 上一个 / 下一个画面（按布局顺序循环，同 Ghostty goto_split） | ⌘[ / ⌘] | 工作台 |
| 左 / 右 / 上 / 下边的画面（按画面实际位置，同 Ghostty goto_split:left/right/up/down） | ⌘⌥← / ⌘⌥→ / ⌘⌥↑ / ⌘⌥↓ | 工作台 |
| 第 1–8 个标签 / 最后一个标签（固定） | ⌘1–⌘8 / ⌘9 | 工作台 |
| 搜索 | ⌘P | 工作台 |
| 设置 | ⌘, | 工作台 |
| 下一个等你的 | ⌘J | 工作台 |
| 查找 | ⌘F | 终端 |
| 清屏 | ⌘K | 终端 |
| 全选 | ⌘A | 终端 |
| 放大 / 缩小 / 还原字号 | ⌘= 与 ⌘⇧= / ⌘- / ⌘0 | 终端 |

固定不可改：⌘C 复制、⌘V 粘贴（系统剪贴板语义）、⌘Q 退出（应用菜单），以及 ⌘1–⌘9 切换标签（浏览器和终端应用的通行约定，设置面板只显示一行只读说明，录制时拒绝把它们给别的动作）。

⌘K 保持与 Ghostty 一致，默认清屏；需要留给 Agent CLI 的人可以自己改绑。

画面切换：只有一个画面时无操作；放大中的画面先还原再切换；焦点真正移到目标画面（输入随之过去）。

## 与终端程序的边界

- 可绑定的组合键必须包含 ⌘。⌃、⌥、⇧ 与普通键的组合始终交给终端程序（shell、vim、Claude Code、Codex 依赖它们）。录制时按下不含 ⌘ 的组合直接拒绝并说明原因。
- ⌘C / ⌘V / ⌘Q 为保留键，不能被绑定给其他动作。
- 终端窗格先看按键：属于终端处理的动作就地执行；属于工作台的动作直接返回（不编码给程序），由外层工作台执行；不在表里的 ⌘ 组合仍按原逻辑交给程序。
- 带 ⇧ 的符号键统一归一成「基础键 + ⇧」（`{`→`[`、`}`→`]`、`+`→`=`、`_`→`-`），录制与匹配都按这个规则，避免同一个物理组合有两种写法。

## 存储

与 `~/.config/keepline/appearance`、`colors.json` 一致：每台机器的界面偏好，存放在 `$XDG_CONFIG_HOME/keepline/keys.json`（默认 `~/.config/keepline/keys.json`），不进入 workspace / host 状态。

```json
{ "new_tab": ["cmd-shift-t"], "split_down": [] }
```

- 只写和默认不同的动作；空数组表示「不绑定」。
- 读取时未知动作名或写错的键位整条报错并回到默认（与 `colors.json` 的处理相同，打印到 stderr），不让一个拼写错误吃掉所有快捷键。
- 例外：旧版写入的 `tab_1`…`tab_8`、`last_tab` 条目，以及把 ⌘1–⌘9 绑给别的动作的条目，只跳过该条，文件其余部分照常生效。
- 全部恢复默认即删除该文件。

## 冲突检测

- 改绑时若新组合已被另一个动作使用，面板在该行提示「已被「X」使用」，并给出「仍然使用」：把组合移给当前动作，同时从 X 上去掉。
- 读取文件时若出现重复绑定，以先出现的动作（表格顺序）为准，后面的忽略并报错。

## 设置面板

此前没有设置面板，外观只在应用菜单里。新增一个居中浮层（与「本机诊断」同一形态）：

- 入口：侧栏底部「设置」按钮、应用菜单「Keepline → 设置…」、快捷键 ⌘,。
- 页面：「快捷键」（默认）与「外观」两页。
- 快捷键页按组列出动作：「标签与分屏」「终端」「工作台」。每行显示当前键位按钮（固定宽度）；点击进入录制，按钮显示「按下组合键…」，该行整体高亮（raised 底色 + focus 描边），说明「按下新的组合键，需包含 ⌘；Esc 取消」、拒绝原因和冲突提示都紧贴在该行下方、同在高亮框内。录制完成立即生效并保存。
- 与默认不同的行显示描边按钮「恢复」；「恢复」占固定槽位，出现或消失时键位按钮不移动。冲突时「仍然使用」为主按钮（accent），「取消」为描边按钮。
- ⌘1–⌘9 折叠成一行只读的「切换到第几个标签 · ⌘1 – ⌘9」。
- 底部描边按钮「全部恢复默认」与边界说明。
- 面板获得焦点时吞掉所有按键，录制或浏览时不会误触工作台动作；Esc 或 ⌘W 关闭。

## 验收

- 单元测试：键位解析与显示往返、符号归一、冲突检测、默认值（含 ⌘[ ⌘]）、文件读写往返（只写差异）、非法文件回到默认、⌘1–⌘9 固定与旧文件兼容。
- 原生检查 `KEEPLINE_SHORTCUT_EVIDENCE`：⌘T ⌘D ⌘⇧D ⌘1 ⌘⇧[ ⌘⇧] ⌘9，以及 ⌘] ⌘[ 在三个画面间按布局顺序循环，且断言真实输入焦点在目标画面上；⌘⌥ 方向键在「左 | 右上 / 右下」布局里按位置移动、在边缘不动。
- 方向的选择规则（`Layout::neighbour`，有单测）：越过该边且与当前画面有共享边长的画面中，取距离最近的，再取共享边最长的，再取布局顺序在前的；在标签边缘返回空，不循环。
- 原生检查 `KEEPLINE_KEYMAP_EVIDENCE`：默认快捷键生效；在面板中录制把「新建标签」改成 ⌘⇧T 后 ⌘⇧T 生效、⌘T 失效；重启（第二阶段进程读同一配置目录）后仍是 ⌘⇧T；「全部恢复默认」后 ⌘T 恢复。面板明暗主题各截一张图。
