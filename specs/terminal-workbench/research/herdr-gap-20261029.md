# Herdr 对照：Keepline 工作台还缺什么（2026-10-29）

要支撑的决定：Keepline 工作台下一批补哪几项能力。放弃条件：与 Keepline 定位（本机、Codex/Claude、按钮优先的 Agent 工作台）不重叠的 herdr 能力只记录不追。

对照对象：herdr 0.9.3（本机）/ 0.9.5（文档），Keepline `next/` 当前工作区代码（含未提交的"输入跳回底部"）。
herdr 来源：https://herdr.dev/llms-full.txt、GitHub herdrdev/herdr release notes 与 issue、本机 `herdr <子命令> --help`、`~/.config/herdr/config.toml`、`~/.local/state/herdr/agent-detection/`。只读取证，没有在 herdr 里实际操作 UI。

## 作者实际怎么用 herdr

配置几乎全默认，只改了：Agent 列表按优先级排（blocked 置顶）、侧栏默认隐藏、鼠标捕获、选中即复制、rose-pine 主题。没有自定义键位，没装任何 integration，没开通知（只有后台声音），没用 worktree / remote / 插件。当前 5 个 workspace、24 个 tab、32 个 pane，7 个 tab 有拆分，tab 几乎都有名字。另外，作者用 `herdr agent prompt/read/wait/send-keys` 让 Claude 驱动 pane 里的 Codex。

## 差距与决定

| # | 能力 | herdr 做法 | Keepline 现状 | 决定 |
|---|---|---|---|---|
| 1 | 中断后自动续接 Agent | 装 integration 后 hook 上报 session id，server 重启时依次 `claude --resume` / `codex resume` | 中断画面只重开普通 shell，要手动点"接着聊"（`workbench/mod.rs:321`） | 采用，最高优先。Keepline 已知道画面对应的会话 id，不需要 hook |
| 2 | 外部驱动画面的 CLI | `pane run/send-text/send-keys/read/wait-output`，`agent prompt --wait --until idle`（blocked 时拒发）、`agent read` 拼全屏历史、事件订阅 | `keeplined` 只有 serve/scan/hook；协议有 Attach+Input 但会抢写入权 | 采用。作者正依赖这类命令做 Claude→Codex 接力；先做 list / read / prompt / wait 四个 |
| 3 | 通知与声音的设置入口 | `toast.delivery` 四档、完成/需要输入各自声音、按 agent 静音、正在看的不弹 | 通知代码在，但 `Settings.notifications` 默认关且没有任何界面能打开（`model.rs:36`）；没有声音 | 采用。补设置页（通知、声音、stale_days、away_minutes、默认 Agent） |
| 4 | 状态识别规则可查、可调 | 规则是 TOML，按屏幕区域匹配，后台热更新，`agent explain` 说明命中哪条 | 有画面兜底扫描，规则写在代码里，误判时看不出原因 | 待验证。先在画面菜单加"为什么是这个状态"，规则外置等出现误判再做 |
| 5 | 键盘操作画面与标签 | prefix 体系：分屏、方向切焦点、交换、zoom、调整大小、新建/切换 tab | 只有约十个写死的 Cmd 键，没有切画面、新建/切换标签、分屏快捷键 | 采用（作为按钮的补充，遵守 product.md "每个功能都有按钮"）：Cmd+T、Cmd+1…9、Cmd+D / Cmd+Shift+D、Cmd+Option+方向键 |
| 6 | 布局整理 | pane 交换、移到别的 tab / workspace 不断进程；tab 重排；workspace 可关 | 不能移动/交换画面，标签不能排序，空间不能删 | 采用：标签拖动排序、删除空间、画面"移到标签…"。交换画面待验证 |
| 7 | 跨回看复制与搜索 | 复制模式（键盘移动、`/ ? n N` 搜索），`prefix+e` 用 $EDITOR 打开回看，滚动条 | 只能复制当前一屏；搜索列结果但无高亮、无上一个/下一个；无滚动条 | 采用：拖选跨回看（拖到边缘自动滚动）、搜索高亮与上下跳、滚动条。键盘复制模式否定（不符合按钮优先） |
| 8 | 新建标签时命名 | 新建 tab 先问名字 | 留空时取程序标题，可双击改名 | 否定。Keepline 自动取 Agent 对话标题，比手填更省事 |
| 9 | git worktree | 一键建 worktree 并作为子 workspace，侧栏显示分支和 ahead/behind | 无 | 待验证。作者 herdr 里没用，但 Keepline 自己的开发常用 worktree；先只在空间行显示分支 |
| 10 | 布局导出/应用 | `layout.export` / `layout.apply` 声明式重建 tab | 无 | 否定（当前）。依赖 #2 的 CLI，没人要求 |
| 11 | 远程 / 多机器 | ssh 内运行、`--remote`、`machine add` 合并多台 | 无 | 否定。产品卡定位为本机 macOS |
| 12 | 插件、23 种 Agent、弹窗终端 | 插件市场、读屏识别 23 种 Agent、浮动终端 | 只识别 Codex/Claude | 否定。超出范围 |

## Keepline 已经领先或持平的

- 打字跳回底部：持平（herdr 默认且不可关）。
- 后台升级时 PTY 交接：Keepline 默认就有，herdr `update --handoff` 仍是实验项。
- 原生 GPU 渲染与输入法：Keepline 原生实现候选窗；herdr 作为 TUI 依赖外层终端，刷新封顶 60Hz（#1134 是最高票开放 issue）。
- 图片粘贴、多行粘贴确认、待办与验收、鸟瞰、清理、官方状态源（`claude agents --json`、Codex app-server）、本机诊断：herdr 没有对应物。
- "下一个等你的"与命令面板：覆盖 herdr 的 `prefix+o` / `prefix+g`。

## 未验

- herdr 0.9.4/0.9.5 的新功能只看了文档，没在本机实测。
- herdr 与 Keepline 的输入延迟、刷新率没有实测对比，"Keepline 更流畅"是架构推断。
