## 方法与边界

- 直接从用户 ZIP 读取原稿，不使用手写仿制基准。只归一化会话、目标、待办、回顾记录与统计数字；不改模板、CSS、按钮文字、设置说明或派发提示词。
- 同一 Chrome，设备缩放 1，时区 Asia/Shanghai，时钟固定为 2026-10-07 13:02；字体、图标和 React 由本地等价资源加载。
- PNG 解码后逐个比较 RGBA；容差为 0，无遮罩。截图同时记录尺寸；不做缩放后比较。动画截图时禁用，鼠标移出内容。
- 页面项比较完整视口，含导航和页头；组件项单独标明。视口外的长页面内容没有因此自动被验收。设置另测 1440×1200；额外覆盖 1920×1080、390×844。
- API 在独立浏览器上下文中全部拦截为测试数据，包括查看详情心跳，不向真实 API 写入。浏览器测试没有脚本异常。
- 无缺口待核对、无确认要求项的新回复、空列表以及多状态同时出现均进入本轮验收，避免只选择容易通过的单卡数据。
- PASS 只代表该条目、该数据和视口下零差异；功能可用、同色、或同尺寸均不能单独代表像素验收通过。
